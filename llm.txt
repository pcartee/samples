# Paul Cartee Writing Samples

> Portfolio of technical writing by Paul Cartee, a senior technical writer specializing in docs-as-code, CI/CD workflows, API and CLI references, cybersecurity, confidential computing, identity verification, and cloud infrastructure.

The canonical site is https://pcartee.github.io/samples/. The homepage introduces Paul and highlights selected work; the [resume](https://pcartee.github.io/samples/paul-cartee-technical-writer/) provides professional history and skills.

## Portfolio sections

- [Capacity planning](https://pcartee.github.io/samples/Capacity%20planning/cloud-infrastructure-demand/): Cloud infrastructure demand planning, capacity approvals, forecasting, and supply buildout processes.
- [Confidential Computing](https://pcartee.github.io/samples/Confidential%20Computing/Concepts/concept-attestation-overview/): Intel Trust Authority samples covering remote attestation, trusted execution environments, TPMs, APIs, CLI workflows, Kubernetes, integrations, and key brokering.
- [Cybersecurity](https://pcartee.github.io/samples/Cybersecurity/cybersec-api-overview/): LogRhythm samples covering API references, authentication, installation, and disaster recovery.
- [Identity verification](https://pcartee.github.io/samples/ID%20verification/Operation%20Guide/operations-guide/): Identity Router operations and administration, with a related [API reference](https://pcartee.github.io/samples/reference/identity-router-api/).
